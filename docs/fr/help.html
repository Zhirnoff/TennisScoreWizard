Tennis Score Wizard

Centre d’aide

Découvrez comment configurer et compter les matchs, les synchroniser via iCloud, connecter Companion à l’iPhone, comprendre les statistiques, enregistrer des entraînements dans l’app Santé, utiliser les complications et résoudre les problèmes courants.

Bien démarrer

Tout ce qu’il faut pour préparer Tennis Score Wizard et commencer votre premier match.

De quoi ai-je besoin pour utiliser Tennis Score Wizard ?

Vous avez besoin d’une Apple Watch compatible sur laquelle Tennis Score Wizard est installé. L’autorisation Santé est facultative et n’est requise que pour enregistrer le match comme entraînement et recueillir les données de santé disponibles.

Comment démarrer mon premier match ?

Ouvrez l’app, choisissez Simple ou Double, la longueur du match, la règle de set et le premier serveur. Activez éventuellement « Enregistrer l’entraînement », puis démarrez le match.

L’app mémorise-t-elle mes réglages ?

Oui. La configuration précédente est enregistrée afin de préparer plus rapidement un match similaire. Vous pouvez toujours modifier chaque option avant le début.

Puis-je compter les points sans Santé ?

Oui. Le score, les statistiques et l’historique fonctionnent sans autorisation Health. Celle-ci est nécessaire uniquement pour l’entraînement et les mesures telles que la fréquence cardiaque et l’énergie active.

Configurer un match

Choisissez le format et les règles correspondant à votre partie.

Quelle est la différence entre Simple et Double ?

Choisissez Simple pour un joueur de chaque côté et Double pour deux joueurs de chaque côté. Le format est enregistré avec le match et utilisé également pour l’entraînement.

Que signifient Meilleur des 3 et Meilleur des 5 ?

En Meilleur des 3, le premier camp à gagner deux sets remporte le match. En Meilleur des 5, il faut gagner trois sets.

Comment fonctionnent les règles de set ?

Sélectionnez la règle correspondant à votre format. L’app détermine automatiquement quand le set est gagné et si un tie-break doit être joué.

Comment choisir le premier serveur ?

Vous pouvez le sélectionner manuellement pendant la configuration ou utiliser le tirage au sort intégré.

À quoi sert le tirage au sort ?

Il produit un résultat aléatoire pour vous aider à choisir le premier serveur. Vous pouvez confirmer le résultat ou ajuster la configuration avant de commencer.

À quoi sert « Enregistrer l’entraînement » ?

Lorsque cette option est activée et autorisée, un entraînement de tennis démarre avec le match. Les données disponibles de fréquence cardiaque, d’énergie active et de durée peuvent être enregistrées dans l’app Santé.

Compter un match

Enregistrez chaque point pendant que l’app gère automatiquement le score de tennis.

Comment enregistrer un point ?

Utilisez les commandes pour indiquer si vous ou l’adversaire avez gagné le point. Le score est mis à jour immédiatement.

L’app calcule-t-elle automatiquement les jeux et les sets ?

Oui. Les points, jeux, sets, égalités, avantages et tie-breaks progressent automatiquement selon les règles sélectionnées.

Comment sont gérés l’égalité et l’avantage ?

À 40–40, le jeu passe à égalité. Un camp doit ensuite prendre l’avantage puis gagner le point suivant. Si l’autre camp gagne, le score revient à égalité.

Comment fonctionne le score du tie-break ?

Lorsque la règle sélectionnée impose un tie-break, l’app passe des points de tennis habituels à un score numérique de tie-break.

Qu’est-ce qu’un tie-break décisif et comment le lancer ?

Il remplace le dernier set décisif. À 1–1 dans un match au meilleur des 3 ou 2–2 au meilleur des 5, ouvrez Menu avant le set décisif, choisissez Match Tie-Break, puis 7 ou 10 points. Il faut deux points d’écart. Cette option fonctionne en simple et en double ; le résultat est enregistré dans l’historique, les détails, les statistiques et les cartes de partage.

Quelle différence avec un tie-break de set ?

Un tie-break de set décide un seul set, généralement à 6–6, enregistré 7–6. Le tie-break décisif remplace l’intégralité du set décisif et apparaît séparément, par exemple [10–7].

Comment fonctionne le marqueur de service ?

Lorsque vous servez, la balle indique le côté depuis lequel vous devez servir. Quand l’adversaire sert, elle montre son côté depuis votre point de vue sur la montre.

Comment l’app suit-elle le serveur ?

Le serveur change automatiquement au fil des jeux et des points de tie-break. Si l’affichage ne correspond plus au match réel, vous pouvez le corriger dans le menu.

Quand faut-il changer de côté ?

L’app affiche un rappel aux changements de côté appropriés. Ce message est informatif et disparaît lorsque le jeu reprend.

Commandes du match

Corrigez une erreur, gérez le match en cours et arrêtez proprement une partie inachevée.

Comment fonctionne Undo ?

Annuler retire le dernier point et restaure l’état précédent : points, jeux, sets, serveur, côté de service, tie-break et statistiques associées.

Que fait Menu ?

Pendant le match, le menu permet notamment de corriger le serveur, ouvrir l’historique, arrêter le match ou préparer une nouvelle partie.

Quand utiliser « Changer de serveur » ?

Utilisez cette action lorsque le serveur affiché ne correspond pas au match réel. Elle corrige le côté au service sans modifier le score.

Que se passe-t-il lorsque j’arrête un match ?

Un match inachevé peut être enregistré avec son score actuel, sa durée, les sets terminés, le set en cours, les points et les statistiques disponibles. Il reste marqué « Arrêté » dans l’historique. Si un camp menait, le résultat compte aussi dans le bilan, le taux de victoires et les séries ; à égalité, il reste neutre.

Puis-je commencer un nouveau match après avoir terminé ou arrêté le précédent ?

Oui. Revenez à la configuration et démarrez une nouvelle partie. La configuration précédente reste disponible pour être réutilisée.

Que faire après avoir ajouté un mauvais point ?

Utilisez Annuler dès que possible. Cela restaure précisément l’état complet antérieur à l’erreur, plutôt que d’ajouter un autre point pour compenser.

Adversaires et rivalités

Choisissez sur Apple Watch un adversaire enregistré pour un simple et construisez automatiquement un bilan privé en face-à-face.

Comment créer un adversaire ?

Ouvrez Rivalités dans Companion sur iPhone. Saisissez-y le nom complet et un nom court pour la Watch. Ce dernier est limité à 16 caractères afin de rester lisible pendant la configuration et le match. Standalone sur Apple Watch peut ensuite choisir les adversaires synchronisés, mais ne permet pas de créer ni de modifier les profils.

Comment choisir un adversaire sur Apple Watch ?

Choisissez Simple pendant la configuration, ouvrez Adversaire, puis sélectionnez Invité ou un joueur enregistré. Un match Invité est enregistré normalement sans être ajouté à une rivalité. En double, aucun adversaire unique n’est attribué au match par équipes.

Que comprend le face-à-face ?

Il utilise les matchs en simple décidés et attribués à ce joueur. Les matchs terminés et les matchs arrêtés avec un leader clair comptent ; un match arrêté à égalité reste neutre. Lorsque les données existent, le profil peut aussi afficher sets, jeux, tie-breaks, points, service et retour, balles de break, temps, entraînements et liste des rencontres.

Que signifie « 5 derniers vs toute la période » ?

La vue compare votre taux de victoires sur les cinq dernières rencontres décidées à celui de toute la période sélectionnée. S’il y en a moins de cinq, elle utilise les rencontres disponibles. Le résultat suit le filtre Toute la période, Cette année ou 30 derniers jours.

Qu’est-ce qu’une victoire après la perte du premier set ?

C’est un match décidé que vous avez gagné après avoir perdu le premier set terminé. « 2 sur 5 » signifie deux victoires parmi cinq matchs concernés ayant commencé par la perte du premier set ; ce n’est pas une limite de tentatives.

Que signifient série actuelle et meilleure série de victoires ?

La série actuelle est la dernière suite ininterrompue de victoires ou de défaites dans des matchs décidés. La meilleure série est la plus longue suite de victoires dans la période sélectionnée.

Puis-je attribuer un ancien match à un joueur ?

Oui. Ouvrez le simple enregistré sur iPhone, choisissez Attribuer dans la section Adversaire, puis sélectionnez le joueur. Vous pouvez modifier ou retirer l’attribution sans changer le score ni les statistiques.

Comment l’app évite-t-elle les doublons ?

Chaque joueur possède un identifiant interne stable. À la création, l’app compare aussi les versions normalisées du nom complet et du nom pour la Watch. La synchronisation utilise cet identifiant et les informations de suppression afin de mettre à jour le même profil plutôt que de le recréer.

Les notes privées sont-elles partagées ?

Non. Elles restent dans le profil et sont exclues du texte et des cartes partagés. Les cartes utilisent le filtre de période actif et conservent un ordre fixe : bilan et rencontres récentes, performance du match, puis tendances et contexte d’entraînement.

Comprendre les statistiques du match

Découvrez ce que représentent les valeurs enregistrées et comment elles sont produites.

Que sont les points totaux ?

Ils indiquent combien de points ont été enregistrés pendant le match. Le résumé distingue vos points gagnés de ceux de l’adversaire.

Que sont les jeux enregistrés ?

Ce sont les jeux contenant des données point par point. Dans un match arrêté, ils peuvent inclure le jeu en cours non terminé ; cette valeur n’est donc pas le score officiel en jeux.

Que montrent les statistiques de balles de break ?

Elles affichent les balles de break concédées et sauvées sur votre service, ainsi que les occasions et les balles de break converties en retour. Les points de tie-break sont exclus.

Les statistiques sont-elles mises à jour automatiquement ?

Oui. Elles sont calculées à partir des points enregistrés. Annuler retire également l’effet statistique du dernier point.

Pourquoi les statistiques d’un match arrêté peuvent-elles être incomplètes ?

Un match arrêté contient uniquement les points et situations survenus avant son arrêt. Les statistiques nécessitant des événements ultérieurs ou une fin normale peuvent manquer.

Pourquoi les anciens matchs affichent-ils moins de statistiques ?

Les matchs enregistrés avec une ancienne version peuvent ne pas contenir les données ajoutées plus tard. L’app conserve les informations réellement enregistrées sans inventer les valeurs absentes.

Synchronisation entre Companion et l’iPhone

Comptez les points sur l’Apple Watch, puis consultez sur l’iPhone l’historique, les résultats, les statistiques et les données d’entraînement synchronisés.

Où configurer et compter les matchs dans Companion ?

La configuration et le comptage en direct restent sur l’Apple Watch. Companion inclut l’app Watch complète et ajoute une vue sur iPhone pour consulter les matchs enregistrés après une session ou entre deux matchs.

Que voit-on sur l’iPhone ?

L’app iPhone peut afficher le dernier résultat, l’historique récent et complet, les scores des sets et des tie-breaks, la durée, les points, les statistiques de service, de retour, de balles de break et de déroulement du match, ainsi que les résumés d’entraînement disponibles.

Comment l’historique se synchronise-t-il ?

Companion dispose de deux voies de synchronisation indépendantes. Watch Connectivity peut envoyer un match enregistré directement entre l’Apple Watch et l’iPhone jumelés, ce qui constitue généralement la voie locale la plus rapide lorsque les deux appareils sont disponibles. CloudKit assure séparément une synchronisation iCloud durable ainsi que la restauration entre Standalone et Companion avec le même compte Apple. Aucune voie ne doit se terminer avant l’autre ; si les deux transmettent le même match, les apps conservent un seul enregistrement à jour.

Que faire si un match n’apparaît pas sur l’iPhone ?

Vérifiez que la bonne Apple Watch est jumelée, gardez les deux appareils à proximité et ouvrez Tennis Score Wizard sur l’Apple Watch et l’iPhone. Vérifiez également que les deux appareils utilisent le compte Apple souhaité et consultez l’état iCloud dans l’Historique. Pendant l’attente, le match enregistré reste protégé localement et pourra se synchroniser dès que la connexion entre appareils ou iCloud sera disponible.

Les données d’entraînement sont-elles aussi synchronisées ?

Lorsque les données sont disponibles, Companion peut afficher sur les deux appareils la durée du match, la fréquence cardiaque moyenne et maximale et l’énergie active avec le match enregistré.

Que se passe-t-il lorsque je supprime l’historique ?

La suppression d’un match ou de tout l’historique dans Companion est synchronisée entre l’iPhone et l’Apple Watch et, lorsqu’il est disponible, via iCloud. L’app demande confirmation avant de supprimer tout l’historique.

Synchronisation et restauration via iCloud

Synchronisez les matchs enregistrés entre Standalone et Companion sans créer de compte Tennis Score Wizard.

Que faut-il pour synchroniser les matchs avec iCloud ?

Assurez-vous que l’Apple Watch et, avec Companion, l’iPhone utilisent le même compte Apple. Activez iCloud Drive, conservez une connexion à Internet et laissez la première synchronisation se terminer. Vous pouvez continuer à compter les points sans iCloud.

Standalone et Companion peuvent-ils partager des matchs ?

Oui. Les deux versions utilisent le même stockage iCloud pour les matchs enregistrés. Avec le même compte Apple, un match enregistré dans Standalone peut apparaître dans Companion et inversement.

Comment savoir si la synchronisation est terminée ?

Ouvrez l’Historique et consultez la ligne iCloud. Synced signifie que la dernière synchronisation a réussi et en affiche la date et l’heure. Syncing signifie que la synchronisation est active. Waiting avec Saving signifie qu’une modification locale est placée en toute sécurité dans la file d’attente iCloud. Sync paused avec Retry signifie que la dernière tentative n’a pas pu aboutir ; touchez la ligne pour réessayer.

Que se passe-t-il si je change de compte Apple ?

Chaque compte Apple possède son propre historique de matchs privé dans CloudKit. Les historiques de comptes différents restent séparés et ne sont pas fusionnés. Lorsque l’app détecte un changement, elle affiche l’historique local et iCloud du compte Apple actuel ; si vous revenez au compte précédent, son historique réapparaît après la synchronisation. Avant que le cache local du compte précédent soit supprimé de cet appareil, les matchs encore en attente de synchronisation sont conservés dans une copie de récupération chiffrée liée à ce compte. Ils ne sont pas envoyés vers le nouveau compte, et changer de compte ne supprime aucun enregistrement déjà stocké dans la base de données iCloud de l’un ou l’autre compte.

Mes matchs seront-ils restaurés après une réinstallation ?

Oui, s’ils ont été correctement synchronisés avant la suppression de l’app. Vérifiez d’abord que l’Historique affiche Synced. Après la réinstallation, utilisez le même compte Apple, gardez iCloud Drive activé, ouvrez l’app et laissez les matchs se télécharger.

Supprimer l’app efface-t-il l’historique iCloud ?

Non. Supprimer l’app n’efface pas automatiquement les matchs déjà synchronisés avec iCloud. Ils peuvent être téléchargés de nouveau après la réinstallation. Si vous supprimez des matchs dans Tennis Score Wizard, ces suppressions sont synchronisées dès qu’iCloud est disponible.

Le développeur peut-il voir mes matchs synchronisés ?

Non. CloudKit stocke les enregistrements synchronisés dans la base de données privée de votre compte Apple. Par défaut, seul cet utilisateur peut accéder à la base de données privée.

Santé et entraînements

Enregistrez votre séance de tennis et comprenez les données de santé affichées après le match.

Comment enregistrer un entraînement de tennis ?

Activez « Enregistrer l’entraînement » lors de la configuration et accordez les autorisations Santé. L’entraînement commence avec le match et se termine lorsque celui-ci est fini ou arrêté.

Comment fonctionne la fréquence cardiaque en direct ?

Pendant un entraînement, la fréquence cardiaque actuelle apparaît lorsque Health est autorisé et que l’Apple Watch fournit un échantillon disponible.

Que sont les fréquences cardiaques moyenne et maximale ?

La moyenne résume les échantillons disponibles pendant l’entraînement. La valeur maximale correspond à la mesure la plus élevée enregistrée.

Qu’est-ce que l’énergie active ?

Il s’agit de l’énergie estimée dépensée grâce à l’activité pendant l’entraînement. Apple Watch et Santé la calculent à partir des données de santé et de mouvement disponibles.

Où l’entraînement est-il enregistré ?

Après une fin réussie, il est enregistré dans l’app Santé et peut également apparaître dans l’app Forme d’Apple, selon les autorisations et la synchronisation.

Pourquoi les statistiques d’entraînement peuvent-elles apparaître avec retard ?

Certaines mesures sont finalisées par Santé après la fin de l’entraînement. Attendez un court moment pour le traitement et la synchronisation, puis rouvrez le match.

Pourquoi une statistique de santé manque-t-elle ?

L’autorisation peut être absente, le capteur peut avoir fourni trop peu d’échantillons, l’entraînement peut avoir été désactivé ou Health peut encore traiter les données.

Le match est-il enregistré si l’entraînement échoue ?

Oui. Le score et l’historique sont indépendants d’Santé. Un problème d’autorisation ou de données d’entraînement n’empêche pas l’enregistrement du match.

Historique des matchs

Consultez les résultats terminés et arrêtés grâce à une notation de tennis compacte.

Que signifient Win et Loss ?

Win signifie que vous avez gagné le match terminé aux sets. Loss signifie que l’adversaire a gagné le match terminé aux sets.

Que signifie Stopped ?

Le match a été enregistré avant sa fin normale. Le contexte réel enregistré jusqu’à cet instant est conservé. Un match arrêté avec un leader compte dans le bilan, le taux de victoires et les séries ; un match arrêté à égalité reste neutre.

Que sont S1, S2 et S3 ?

Ils désignent le set 1, le set 2 et le set 3. Par exemple, « S1 6–3 » signifie que le premier set s’est terminé par six jeux à trois.

Que signifie TB 7–3 ?

TB indique les points du tie-break dans le set. « 7–6 · TB 7–3 » signifie que le set s’est terminé 7–6 et le tie-break 7–3.

Que signifie 7–6(6) ?

Le petit nombre entre parenthèses est le score du joueur qui a perdu le tie-break. 7–6(6) signifie que le tie-break s’est terminé 8–6. Les détails du match continuent d’afficher le score complet du tie-break.

Comment les matchs arrêtés sont-ils évalués ?

L’app compare d’abord les sets terminés, puis les jeux enregistrés et enfin les points de tie-break disponibles. Si un camp mène, le résultat compte comme une victoire ou une défaite dans les statistiques, tandis que le match reste marqué « Arrêté ». Si le score est toujours à égalité, le résultat est neutre.

Que devient un set non terminé ?

Si le set en cours a déjà commencé, son état est enregistré avec le match, par exemple « S3 0–1 ».

Quelles informations sont enregistrées avec un match ?

L’historique peut inclure le résultat, les scores des sets, les tie-breaks, les points, la durée, les heures de début et de fin, les statistiques et les données d’entraînement disponibles.

Puis-je supprimer un match enregistré ?

Oui. Utilisez l’action de suppression dans l’historique et confirmez. L’entrée enregistrée sera retirée de l’app.

Soutien facultatif au développement

Un soutien ponctuel contribue aux futures évolutions, mais ne déverrouille aucune fonction et ne modifie pas l’app.

Un pourboire déverrouille-t-il quelque chose ?

Non. Les pourboires Apple et le soutien en cryptomonnaie sont facultatifs. Toutes les fonctions restent disponibles selon le produit acheté, avec ou sans contribution.

Comment fonctionne un pourboire Apple ?

Choisissez un montant ponctuel dans Infos → Soutenir le développement, puis confirmez-le dans la fenêtre d’achat Apple. Apple traite le paiement avec le moyen associé à votre compte App Store.

Que vérifier avant un soutien en cryptomonnaie ?

Vérifiez dans votre portefeuille la devise, le réseau et l’adresse de destination complète. Les transferts blockchain sont généralement irréversibles. Tennis Score Wizard n’associe aucune donnée de match, de rivalité, d’entraînement ou de Santé à la transaction.

Complications de cadran Apple Watch

Accédez rapidement à Tennis Score Wizard depuis un cadran compatible.

À quoi sert la complication Tennis Score Wizard ?

Elle agit comme un raccourci. Touchez-la pour ouvrir Tennis Score Wizard sur l’Apple Watch.

Quelles familles de complications sont prises en charge ?

Tennis Score Wizard prend en charge les emplacements circulaires et d’angle pour les complications sur les cadrans Apple Watch compatibles.

Comment ajouter la complication ?

Modifiez un cadran compatible sur l’Apple Watch ou dans l’app Watch de l’iPhone, choisissez un emplacement pris en charge, puis sélectionnez Tennis Score Wizard.

Pourquoi la complication n’apparaît-elle pas ?

Vérifiez que l’app est installée sur l’Apple Watch et que l’emplacement choisi prend en charge une famille compatible. Les emplacements disponibles varient selon le cadran.

Pourquoi son apparence change-t-elle selon le cadran ?

Apple Watch définit la forme et l’espace de chaque emplacement. Tennis Score Wizard adapte automatiquement son raccourci à la présentation circulaire ou en coin.

Dépannage

Vérifications courantes lorsque le score, les données d’entraînement ou l’accès depuis le cadran ne fonctionnent pas comme prévu.

La fréquence cardiaque en direct ne s’affiche pas.

Vérifiez que l’entraînement est activé, que Health est autorisé et que la montre est correctement portée. La valeur apparaît uniquement lorsqu’un échantillon est fourni par l’Apple Watch.

L’entraînement n’apparaît pas dans l’app Santé.

Attendez le traitement, vérifiez les autorisations et confirmez que l’enregistrement était activé. Assurez-vous également d’avoir terminé ou arrêté le match correctement.

La fréquence moyenne, la fréquence maximale ou l’énergie active manque.

Rouvrez le match après avoir laissé à Santé le temps de finaliser l’entraînement. Une valeur peut rester indisponible si les données sources sont insuffisantes.

Le serveur affiché est incorrect.

Ouvrez le menu et utilisez « Changer de serveur ». Cette action corrige le côté au service sans modifier le score.

J’ai enregistré le mauvais point.

Utilisez Annuler pour restaurer l’état précédent, y compris le score, le serveur, le tie-break et les statistiques associées.

La complication n’est pas disponible sur mon cadran.

Essayez un emplacement circulaire ou d’angle. Tous les emplacements de tous les cadrans ne prennent pas en charge le même type de complication.

La réinstallation conserve-t-elle l’historique ?

Ouvrez d’abord l’Historique et vérifiez que la ligne iCloud affiche Synced. Après la réinstallation, utilisez le même compte Apple avec iCloud Drive activé et laissez la restauration se terminer. Les matchs qui n’ont jamais terminé une synchronisation iCloud restent uniquement sur l’appareil d’origine.

L’Historique affiche Waiting, Saving ou Sync paused avec Retry.

Waiting avec Saving signifie qu’une modification locale est en attente et pourra être envoyée dès qu’iCloud sera disponible. Si Sync paused apparaît avec Retry, vérifiez que l’appareil est connecté au compte Apple souhaité, qu’iCloud Drive est activé, que le réseau est disponible et que le stockage iCloud n’est pas plein, puis touchez la ligne d’état. Les matchs locaux ne sont pas supprimés simplement parce qu’iCloud est indisponible.
