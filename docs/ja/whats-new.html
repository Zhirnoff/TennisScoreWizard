Companionのリリース

iPhoneと連携する、完全なWatchアプリ。

現在利用可能

バージョン1.0では、Apple Watchでのスコア管理機能をすべて網羅するとともに、試合履歴、結果、詳細な統計データ、ワークアウトの分析情報をiPhoneのホーム画面と同期して表示します。

初回リリース

バージョン 1.0

  • 試合設定、ライブスコアリング、サーブガイド、元に戻す機能、履歴、自動統計、ワークアウト、コンプリケーションを網羅した完全なApple Watchアプリ。
  • Apple WatchからペアリングされたiPhoneへの、ローカルな試合履歴の自動同期。
  • 最新の結果、最近の試合、保存された試合履歴のすべてを表示するiPhoneのホーム画面。
  • 勝敗、セットとタイブレークのスコア、試合時間、ポイント、サーブ、リターン、ブレークポイント、試合の流れを詳しく振り返れます。
  • Apple Healthから取得可能な場合、平均心拍数、最大心拍数、アクティブエネルギーを含むワークアウトの概要。
  • 個々の試合や履歴全体を削除でき、変更内容はiPhoneとApple Watch間で同期されます。
Standalone

改良を重ねて進化するApple Watchアプリ。

現在利用可能

Standaloneは、Apple Watch専用の完全な体験を提供し続けています。バージョン1.0以降、どのように進化してきたかをご紹介します。

最新リリース

バージョン 1.3.1

  • Apple Watchの履歴から保存されたすべての試合を一度の操作で削除できます。
  • 明確な確認手順により、履歴全体の誤削除を防ぐことができます。
  • バージョン 1.3 で導入された Apple Watch 文字盤のコンプリケーションが含まれています。
Version 1.3

Apple Watchの文字盤からアクセス

  • Apple Watchの文字盤用コンプリケーション。
  • accessoryCircularおよびaccessoryCornerコンプリケーションファミリーに対応。
  • 対応するウォッチフェイスからの直接起動。
  • 新しいヘルプセンターと改良されたオンラインドキュメント。
Version 1.2.1

ワークアウトの信頼性

  • より信頼性の高いワークアウト統計。
  • 心拍数およびアクティブエネルギーデータの精度向上。
  • ワークアウトの完了処理および履歴の更新が改善されました。
Version 1.2

自動マッチ統計

  • ポイント、サーブ、リターン、ブレークポイント、試合の流れに関する統計。
  • 試合履歴でのポイント概要。
  • アプリ内ヘルプの更新およびインターフェースの改良。
Version 1.1

Apple Health ワークアウト

  • テニスワークアウトの記録とリアルタイム心拍数。
  • 試合時間とワークアウトの詳細。
